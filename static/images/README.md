# Images Directory

## Banner Image

To replace the default banner with your custom "Idea Hub" image:

1. Save your banner image as `idea-hub-banner.png` in this directory
2. The image should be optimized for web (recommended: 1200x400px)
3. The CSS will automatically use your custom image if it exists

## Current Status

- **Default**: CSS gradient background with Red Hat theme
- **Custom**: Replace with your "Idea Hub - Innovate Together, Powered by AI" banner

## Instructions

```bash
# Place your banner image here:
static/images/idea-hub-banner.png
```

The header will automatically detect and use your custom banner image!
